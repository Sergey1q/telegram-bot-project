# 🤖 Telegram-бот с веб-админкой и платежами Telegram Stars

Полноценный коммерческий проект для автоматизации бизнеса.

## 🚀 Возможности

### Бот
- 📅 Запись клиентов на услуги
- 💰 Оплата через Telegram Stars ⭐
- 📝 Система отзывов с рейтингом
- 📊 Статистика для администратора
- 📤 Экспорт данных в Excel
- 📢 Массовая рассылка

### Веб-админка (FastAPI)
- 📊 Дашборд с графиками
- 📋 Управление заявками (CRUD)
- 👥 Управление пользователями
- 🔧 Управление услугами
- 📢 Рассылки с историей
- 📤 Экспорт в Excel

## 🛠 Технологии

| Технология | Назначение |
|------------|------------|
| Python 3.13 | Язык программирования |
| Aiogram 3 | Telegram Bot API |
| FastAPI | Веб-админка |
| SQLAlchemy | ORM для БД |
| SQLite | База данных |
| Pandas | Экспорт в Excel |
| Chart.js | Графики в админке |
| Bootstrap 5 | UI админ-панели |
